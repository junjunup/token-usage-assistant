# 安全问题报告 / Security

## 中文

发现安全问题（例如凭据可能被记录、导出或发送到不该去的地方，能读到对话内容，或者可以绕过只读限制）时，**请不要公开开 issue**。

- 首选：在本仓库的 **Security → Report a vulnerability** 私下报告。
- 如果该入口不可用：开一个**不含细节**的 issue，标题写「需要私下联系：安全问题」，我们会回复联系方式。

请附上：受影响的版本、系统、复现步骤，以及你认为的影响。请勿附上真实的 API Key、令牌、账户名或对话内容，用打码后的截图或合成样例说明即可。

支持范围：最新发布的版本（目前是 1.9.0 测试版）。数据边界见 [隐私说明](docs/PRIVACY.md)。

## English

If you find a security problem (for example credentials being logged, exported or sent where they should not go, conversation content being readable, or a way around the read-only limits), **please do not open a public issue**.

- Preferred: report it privately via **Security → Report a vulnerability** in this repository.
- If that is unavailable: open an issue **without details** titled "Need private contact: security", and we will reply with a contact.

Please include the affected version, OS, steps to reproduce, and the impact you see. Do not attach real API keys, tokens, account names or conversation content; masked screenshots or synthetic samples are enough.

Supported: the latest release (currently the 1.9.0 beta). Data boundaries: [Privacy](docs/PRIVACY.md).
