# Token 用量助手 1.8.0-beta.3 · 刻度环标识

用户于 2026-09-26 批准精修后的刻度环 Logo，明确保留原来的详情页和整体 UI。此版本仅将应用图标、系统托盘、加载标识、侧栏和悬浮窗品牌标识替换为同一份刻度环矢量。

## 设计来源

- 确认稿：`brand/approved-ring-r2.png`；保留长弧、右上短弧及两处斜切口。
- 矢量母版：`../desktop/assets/brand-mark.svg`，从确认稿的黑色主图自动描摹，来源哈希和提取参数见 `brand/source.json`。
- 原有绿色 #10b981 用于系统图标；界面标识继承原有主题颜色，不引入新的调色板、阴影、卡片或字体。
- PNG、包含 16–256 像素的 Windows ICO、Mac ICNS 由 `scripts/build-icons.mjs` 从母版生成。重建需设置 `SHARP_MODULE` 指向可用的 sharp 模块。

## 保留事项

详情页布局、字号、间距、细线、图表、深浅主题、功能图标和交互保持原样；`src/App.jsx` 历史原型也保持原样。仅更新桌面应用中的三个品牌标识及预览版本号。应用 ID、程序名、账户存储、设置和窗口位置代码不变。beta.2 的 Mac Codex 连接修复保留。

## 交付和验证

发布目录 `release-v1.8.0-beta.3` 包含 Windows 安装版、免安装版、Mac ARM64 全量试用包和源码交接包。历史发布不覆盖。验证记录位于 `verification-1.8.0-beta.3`，视觉检查见项目根目录 `design-qa.md`。

Windows 进行定向自动检查、最终免安装包的隔离样例原生启动，以及安装版/免安装版的版本和载荷校验。未实际运行安装向导，未恢复长期稳定性测试。Mac 包沿用官方 Electron 44.4.4 ARM64 运行环境，仍需 Mac 实机确认；未声称签名、公证或新的真实账户验收。
