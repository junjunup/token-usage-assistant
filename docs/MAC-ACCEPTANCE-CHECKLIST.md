> 适用：Apple Silicon、macOS 13+，本机构建的 ad-hoc 签名、未公证的 `Token 用量助手.app`（见 [MAC-APP-1.8.0-beta.5](MAC-APP-1.8.0-beta.5.md) 与 [RELEASING](RELEASING.md)）。
> 由**用户在真机上**逐项执行并填写「实测记录」；用户也可以让 Claude 用 computer use 在这台 Mac、真实账户上代测，结果标注「③（Claude 代测）」（D12 ②，2026-10-23）。需要用户亲自操作的项（改系统设置、输入密码、外接屏、锁屏等）仍由用户做；任何一项没有实测就不得标为通过（证据等级 ③ 只能来自真机）。

## 1. 从 DMG 安装，首次打开

- **步骤**：用浏览器下载 DMG，打开后把「Token 用量助手」拖入「应用程序」；双击打开。出现提示后关掉，到**「系统设置 → 隐私与安全性」**点**「仍要打开」**并确认。
- **预期**：出现「无法验证开发者」提示（弹窗里没有「打开」按钮）；在系统设置里放行后应用启动，出现主窗口和菜单栏图标；不会出现「已损坏，无法打开」。同一版本再次打开不再提示。
- **实测记录**：2026-10-25，macOS 15.7.9，1.9.0-beta.4：Claude 让 Safari 从安装包仓库下载 DMG（哈希与发布一致、带隔离属性）并装入「应用程序」；首次启动时系统挂起应用并弹出「无法验证开发者 / 从互联网下载」一类的提示，**弹窗里没有「打开」按钮**，用户到「系统设置 → 隐私与安全性」点「仍要打开」后应用正常启动（③，放行由用户完成）。原来写的「右键 → 打开」在 macOS 15 上不能放行，已改。

- **预期**：可能出现钥匙串授权提示，条目名为 `TokenUsageAssistant Safe Storage`；选择「始终允许」后账户保存成功。之后重启应用，账户仍在，不再提示。

## 3. 覆盖升级后的 Keychain 授权（每次发版必测）

- **步骤**：
  1. 在已保存账户的旧版本上，安装新构建的 DMG 覆盖（拖入「应用程序」并替换），再打开。
  2. 如果弹出钥匙串授权提示，**第一轮选「拒绝」**：观察应用的表现。
  3. 在应用的错误提示处点「重新读取」（T3.4 新增，按钮界面需按 D10 确认后才会出现在包里；如果当前包里还没有按钮，记为「未测」），这次选「始终允许」。
  4. 再次退出并重开应用。
- **预期**：
  - 第 2 步：账户列表显示「本机账户列表暂不可用，已有加密文件未被覆盖」，**已保存的账户没有丢失**。
  - 第 3 步：不重启应用就能恢复账户列表和当前选中的账户。
  - 第 4 步：不再弹出授权提示，账户都在。
- **实测记录**：显示本机账户列表暂不可用，已有加密文件未被覆盖。请恢复备份后重启助手。

## 4. 开发版与打包版的数据隔离（T3.1）

- **步骤**：在已安装打包版并保存过账户的电脑上，在源码目录运行 `pnpm run desktop`，然后退出。

## 12. 菜单栏动态图标与弹出面板（1.9.0-beta.1，T7.5–T7.7）

- **步骤**：连接至少一个有额度窗口的账户（如 Command Code、Codex 或 GLM），等待同步完成后观察菜单栏图标；左键点击图标；在面板里点其他账户；按 Esc；再左键打开后点面板外；再打开后点「主窗口 ›」。
- **预期**：图标是刻度环 Logo 加一个数值（默认 ②），数值与主窗口中剩余最少的窗口一致（同一账户内先比较 5 小时 / 每周等额度窗口，没有可用窗口时才显示金额；T7.9 起，1.9.0-beta.1 正式包仍是旧规则）；面板出现在图标正下方，宽度与草图一致，默认显示图标对应的账户；点其他账户只切换面板内容，主窗口当前账户不变；Esc、点面板外、再点图标都会收起；「主窗口 ›」打开主窗口并收起面板。没有连接账户时图标为原来的静态 Logo。

  - **复测（2026-10-18，开发包 `1.9.0-beta.1-dev.22dab4c`，含 T7.9 / T7.10）**：图标切到动态后宽 72pt，与「100%」一致（显示 $18.06 时为 78pt），即改为显示额度窗口；面板中 Claude 显示「尚未同步成功，暂无数据。」。**新发现**：面板「其他账户」里 Command Code 的标签仍是「$18.06」，与图标不一致（面板标签用的是自己的选值逻辑，T7.9 没有改到）；覆盖安装后第一次启动停在钥匙串授权窗约 2 分钟，授权后图标一直是静态 Logo，重启应用后才变为动态（见计划第 5 节）。

## 14. 刘海旁空间不足时的隐藏与提示

- **步骤**：在菜单栏图标较多时（或改用 ③ 两行小字）观察本应用图标是否还在；如果看不到，打开主窗口总览和「账户与设置 → 偏好 → 菜单栏图标与面板」。
- **预期**：系统可能把图标藏到刘海后面且不提示；此时总览和设置里都出现琥珀色提示「菜单栏空间不足……可改用「① 只有刻度环」……」，形态**不会**自动改变；改用 ① 或减少其他菜单栏图标后，提示消失。
- **实测记录**：2026-10-18，Claude 用 computer use 在本机（MacBook 内置屏 1512×982pt，macOS 15.7.9）实测已安装的 1.9.0-beta.1 打包版，账户：Command Code（主）+ Claude。**通过（③，Claude 代测）**：退出并重新打开应用后，图标被系统放到了更靠左的位置；切回 ② 后图标左边缘落在 x=847pt（刘海右沿约 848pt），系统把它藏起来且不提示（CGWindowList 中 onscreen=false，菜单栏上看不到）。此时设置页「菜单栏图标与面板」和总览页都出现琥珀色提示「菜单栏空间不足，……可改用「① 只有刻度环」，或减少其他菜单栏图标。」，形态没有自动改变；改用 ① 后图标出现（x=891pt，宽 34pt），两处提示随即消失。**观察**：总览页提示里的「菜单栏设置 ↗」只切到设置页顶部，需要再往下滚才看到这一组。验收后形态留在 ①（改回 ② 图标会再次被藏）；按住 ⌘ 把图标拖到右侧后可改回 ②。
