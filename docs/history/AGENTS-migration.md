>
> 去向分三类：
> - **保留**：在新 AGENTS.md 中有对应条目（§ 为新文档的节号）；
> - **合并**：并入新 AGENTS.md 的某条更通用的规则，或移到 PROJECT_HANDOFF / CHANGELOG；
> - **已过时**：不再进入新 AGENTS.md，附理由。**每条「已过时」都必须由用户确认（填写最后一列）之后，T1.4 才能合并到 main。**
>
> 一条旧规则如果同时包含仍有效和已过时的部分，就拆成 a/b 两行。
