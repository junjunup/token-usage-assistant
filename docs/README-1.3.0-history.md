# Token 用量助手 · Windows 桌面版 1.3.0

按已确认的 Command Code 风格原型开发。白底细线、绿色额度条、紫色 Token 指标，支持深色外观。独立桌面工具，非各平台官方客户端。

换电脑接续开发、使用或 AI 对话，请先阅读 [项目交接文档](PROJECT_HANDOFF.md)。其中包含已完成内容、数据口径、环境恢复步骤与首批多平台适配的验证边界。

## 开始使用

在 release-v1.3 文件夹中任选一种：

- TokenUsageAssistant-Portable-1.3.0.exe：免安装，双击启动，首次解压启动稍慢。
- TokenUsageAssistant-Setup-1.3.0.exe：安装版，可选择安装位置，创建桌面和开始菜单快捷方式。

目标平台为 Windows x64，本机验证环境为 Windows 11。这是未签名的本地开发版本，未发布到互联网。

1. 打开“账户与设置”，选择平台和地区，在本机填入套餐凭据并点击“验证并添加账户”。无需把密钥发到聊天里。
2. GLM / MiniMax 使用所选站点的套餐 Key；火山个人 Agent Plan 使用有 GetAFPUsage 权限的 AK/SK；Command Code 使用 API Key 与可选组织 ID。
3. 顶部切换已保存账户。各平台按官方原单位显示额度窗口与重置时间；新平台暂不提供 Token 或账单统计，Command Code 保留已有统计。
4. 点击“显示悬浮窗”开启独立置顶窗口。点击图钉取消固定，再拖动顶部移动位置。
5. 关闭主面板后仍驻留系统托盘；点托盘图标返回，右键“退出助手”停止运行。

默认每 60 秒刷新，可改为 30 / 60 / 120 / 300 秒。提醒阈值可选 10% / 20% / 30%。开机启动默认关闭，可在设置中开启；启动时静默驻留托盘。

## 1.2 更新：面板与悬浮窗

- **固定导航**：侧栏与标题栏常驻，只有详细内容区域滚动，切换页面回到顶部。
- **统一下拉菜单**：模型、项目、排序、提醒阈值与刷新间隔均使用应用主题菜单。支持方向键、Enter 确认、Esc 关闭和键盘输入定位；供应商与长项目路径分行显示，空间不足时调整弹出方向。
- **月额度置顶**：月余额、已用、账期结束、购买与免费余额都在总览顶部。月度用尽时，即使 5 小时或每周窗口仍有余量，综合状态也不会显示“额度充足”。月度低余额和用尽提醒沿用现有提醒开关，避免重复打扰。
- **月额度口径**：余额来自账户接口；仅在同次同步、同一账期的月度消耗字段有效时，按“余额＋已用”计算账期额度与剩余百分比。缺少数据时只显示已知余额，不根据套餐名猜测额度。
- **悬浮窗**：默认紧凑常驻，新增月度余额及账期日期。点击“展开数据”查看本账期 Token、费用、请求数、成功率、购买与免费余额、最近同步时间。顶部可手动刷新，底部可进入详情；收起后恢复紧凑高度。展开状态保存在本机，窗口扩展时避免伸出屏幕底部。
- **重置状态**：接口明确返回未启动窗口（resetAt=0 且已用=0）时显示“待首次使用后开始计时”；有效时间显示倒计时，已到期显示等待同步，字段缺失则显示“重置时间暂未返回”。不会人为从打开应用的时刻启动一个五小时计时器。

窗口开始计时的规则见 [官方 Pricing & Limits](https://commandcode.ai/docs/resources/pricing-limits#how-the-windows-roll)。悬浮窗展开示例截图为 `widget-expanded-v1.2.jpg`。

## 1.1 新增：用量分析

侧栏第二个四宫格按钮进入独立的“用量分析”页。悬浮窗开关保留在首页和设置中。

1. **时间范围**：今日、近 7 天、本账期；今日和近 7 天按本机时区划分，本账期需连接账户确认起点。
2. **用量趋势**：今日按小时，较长范围按天；可切换 Token、费用、请求数，并展开精确数据表。
3. **模型排行**：按 Token、请求数或估算费用排序；点击模型筛选，并可按供应商分别设置单价。
4. **项目与会话**：按项目目录聚合，点击项目下钻会话，点击会话查看趋势和缓存；不读取会话正文。
5. **缓存分析**：普通输入、缓存读取、缓存写入、读取命中率及估算节省；显示有效字段覆盖率。
6. **请求健康**：成功、失败、取消及其他状态，单次平均 Token 和费用；首页也新增健康摘要。
7. **额度来源**：套餐、购买、免费余额，以及所选时段各来源消耗，缺失字段显示“—”。
8. **消耗速度与预测**：Token / 分钟、费用 / 小时、5 小时与每周窗口的预计触顶情况；基于至少 10 分钟连续且新鲜的账户样本。

### 两种数据来源

- **账户统计**：来自 Command Code 账户 / 组织 API，费用为接口实际费用。趋势按助手采集的汇总差值计算，启动前和离线区间不补零；因此图表覆盖量可能小于接口总量。账户接口暂不提供模型、项目、会话和缓存明细，相关页可切换到本机数据。
- **本机 Zcode**：默认只读 `%USERPROFILE%\.zcode\cli\db\db.sqlite`；支持 ZCODE_HOME 和手动选择数据库。只选择请求时间、模型 / 供应商、状态、Token 计数、会话标识、项目目录，不读取提示词、补全、会话标题、错误正文或原始响应。全部供应商记录在本机分析，与账户总量不能相加。

本机费用为按手动配置单价计算的**估算值**，不代表实际扣费；默认不猜测私有供应商价格。输入、输出、缓存读取、缓存写入四类单价单位均为 USD / 百万 Token。缺少价格或完整 Token 分类的请求显示未定价；用户明确填入 0 才视作该类免费。缓存输入已包含在输入 Token 内，拆分不会重复累计。读取缓存的估算节省不包含缓存写入溢价。

本机请求成功率按完成 /（完成 + 失败）计算，取消和进行中单列；Token 和费用仅累加已完成请求，平均值也以完成数为分母。账户成功率按完成数 / 总请求数计算，平均值按接口总请求数计算，两种口径不混用。

账户历史保存在本机 history.json，每分钟最多一个样本，保留最近 31 天且最多 16,000 个样本（默认 60 秒连续采样约 11 天）。历史不足、离线、过期、账期或额度窗口重置时不强行预测。预测假设近期速度不变，不代表固定剩余 Token 或最终账单。单次本机读取最多 100,000 条，达到上限会提示缩小范围。

## 原有桌面能力

- 原生系统托盘、独立悬浮窗、主窗口最大化和收起。
- 外观、设置和窗口位置保存，主面板与悬浮窗同步。
- 低额度及达到上限时调用 Windows 通知，避免每次轮询重复提醒；额度恢复后重新允许提醒。
- 断网或部分接口失败时保留上次成功数据，并标注状态与更新时间。
- 429 遵循 Retry-After，手动刷新也不能绕过；网络错误逐步退避，认证失败停止自动重试。
- 休眠恢复后刷新；单实例运行，重复打开返回现有窗口。

## 数据与密钥

Command Code 使用 GET 查询 api.commandcode.ai 的身份、余额、订阅与汇总接口；GLM / MiniMax 查询各自固定官方额度接口；火山使用签名 POST GetAFPUsage 只读查询。完整端点和数据口径见首批适配记录。不会发起模型生成请求。

账期确认后，汇总查询带 since 参数；未确认则标为“累计汇总”。缺失字段显示“—”，不补成零或满额。额度按费用计算，不能换算成精确剩余 Token。数据属于账户 / 组织汇总，不能单独归属到 Zcode 或某台电脑。

这些 /alpha 接口尚非公开稳定契约，已做字段校验和失败降级。开发验证未读取用户密钥；已验证真实本机 Zcode 用量元数据的只读聚合。账户接口通过合成响应测试，首次连接仍需核对真实账户与官方页面的一致性。

密钥通过 Electron safeStorage 使用 Windows DPAPI 加密，存于 accounts.encrypted.json。加密不可用时拒绝保存，不降级为明文。升级可读取旧版 credentials.encrypted.json，新版保存成功后才移除旧凭据。设置存于 settings.json；新账户的快照与采样存于 accounts/{UUID}/，旧 Command Code 保留根目录 snapshot.json / history.json。模型价格、数据库选择与窗口位置继续保留。

数据使用 Electron 当前 Windows 用户的 userData 目录。免安装版也使用此目录，不会将密钥写在 EXE 旁。DPAPI 绑定当前 Windows 用户，不应把密钥文件视作跨电脑备份。

“移除当前连接”仅删除所选连接的本地密钥、快照和账户采样，停止该连接查询，保留其他账户与外观偏好，不修改远端账户。不保存账户密码、网页 Cookie、提示词或补全内容。

桌面版通过受限 IPC 通信，不开放 HTTP 监听端口；启用沙箱、上下文隔离和内容安全策略。查询限定固定 HTTPS 域名与只读 GET / POST 接口，不跟随重定向。

## 常见情况

- 密钥无效 / 权限不足：重新连接，并检查组织 ID。
- 连接中断：检查所选平台官网、官方 API 域名的网络和系统代理。
- 没有通知：启用额度提醒并点“测试通知”；显示还受 Windows 通知、勿扰设置影响。
- 悬浮窗无法拖动：先点击图钉取消固定。
- 开机后没有主面板：从系统托盘图标打开。

## 源码与构建

React 19 + Vite 6 + Electron 44，依赖由 pnpm-lock.yaml 固定。构建依赖全部放在 devDependencies，不随运行包携带。用户运行 EXE 不需要 Node.js、pnpm 或浏览器服务器。

```powershell
pnpm install
# 如 pnpm 未执行 Electron 安装脚本，执行：
node node_modules/electron/install.js
pnpm run build
pnpm run test:desktop
pnpm run desktop
pnpm run package:win --config.electronDist=node_modules/electron/dist
```

- desktop/：主进程、IPC、接口适配、轮询、加密存储。
- src/DesktopApp.jsx、src/desktop.css：真实桌面界面。
- tests/desktop.test.cjs、tests/analytics.test.cjs：桌面与分析逻辑测试。
- electron-builder.yml：Windows 打包配置。
- desktop-verification.md：本轮桌面验证记录。

原始原型保留在 src/App.jsx，可通过 ?legacy-prototype 访问。开发服务器根路径展示最新桌面界面，使用示例数据且不能连接密钥；?desktop-preview=empty 可检查空状态。它们与真实桌面程序的数据源分开。analytics-preview-v1.1.jpg 为示例数据截图，design-qa.md 为早期原型检查记录。
