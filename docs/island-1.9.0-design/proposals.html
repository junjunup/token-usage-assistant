  • 悬停意图：耳区停留 ≥150ms 才展开（防划过菜单栏误触）；移出 200ms 宽限后收回；展开 220ms spring 下落。

    槽位制 · 渲染与优先级规则

  • 四型槽位：窗口配额（remainingPercent 有值 → 分段条 + 重置时间）、余额（balances[] + is_available → 等宽数字 + 币种）、不限量（limited=false → 「不限」）、不可用（无已验证数据源 → 「—」）。
  • 耳位优先级：告警中（琥珀/红）> 窗口剩余最少 > 余额低于阈值 > 默认账户；多账户同时告警时叠加数字徽标。空耳位保持纯黑，不编造内容。
  • 诚实红线：resetAt=0 = 窗口显式未启用（「未启用」，绝不发明 5h 倒计时）；缺 reset 数据 = 「—」；余额永不画百分比条；不从余额差推算消耗；余额预估仅基于已确认关联的工具用量且样本充足；订阅百分比永不套用在 API 余额上。
  • 告警：窗口沿用现有 <20%/<10% 阈值；余额阈值用户自设（与"月度余额纳入健康告警"的既有规则一致）；缺数据不告警。

    • 设置页 · 耳区内容自定义SETTINGS

    四层模型：识别账户数据形态后自动默认填充两耳（零配置可用）→ 设置页显式绑定左右耳内容（可选项只列实际存在的槽）→ 告警临时接管（默认开）→ 绑定失效自动回退默认并在设置中如实标记。

    告警临时接管耳区

    任一账户进入告警（琥珀/红）时临时占用耳位并显示徽标，解除后自动恢复绑定内容。多账户同时告警时叠加数字徽标。

    消耗瞬态提示

    轮次消耗时左耳短暂显示「会话 +N」后恢复绑定内容（3–4s）。合并冷却 ≥120s 或累计 ≥5%，避免频闪；跨越阈值或告警时改由接管通道显示。默认开。

    刘海宽度微调

    纯 Electron 拿不到系统刘海精确宽度：默认按内置机型预设表（如 200pt），若耳区内容与刘海边缘间距异常可手动微调（真机校准一次即可）。

    预设 · 200pt

    截屏与共享保护

    防止岛内容出现在截图、录屏与屏幕共享中（如实标注：使用 ScreenCaptureKit 的新版应用仍可能捕获到）。对应 setContentProtection。

    步进刷新频率

    「正在运行」与会话增量的轮询间隔；更快的刷新略微增加本地读取开销，真机验收时提供实测数据。

    默认与回退规则

  • 首次启用自动填充：左耳 = 最紧急窗口槽（有 5h 用 5h）；右耳 = 周配额或首个余额账户；纯 API 组合两耳各一余额账户；单账户只占左耳，右耳留黑。
  • 绑定失效回退：账户删除 / 窗口未启用 / 契约失效 → 该耳自动回退默认规则，设置中如实标记，绝不渲染编造内容。
  • 升级不扰：绑定与告警阈值随既有偏好持久化；升级默认不变（经典悬浮窗仍为默认形态）。

    交付阶段与红线

  • 首版（岛 v1）：槽位岛 + 设置四层 + 截屏保护 + 微动效 + 快捷入口——不依赖新数据管线，纯呈现层。
  • 增量一：reader 增量投影（latest-since-cursor）+ monitor 会话聚合 →「正在运行」、倒计时槽、消耗瞬态、步进刷新生效。
  • 增量二：本地事件存储 + 组件状态聚合 → 事件流面板块、组件健康 chip。
  • 明确不做：终端跳转 / 审批注入（只读红线）· 媒体控制 / HUD · 文件架 / AirDrop · 剪贴板历史 · 摄像头 Mirror。
