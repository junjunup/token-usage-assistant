# Windows 真机验收清单

> 适用：Windows 10 / 11 x64，CI 的 Release 工作流产出的安装版 `TokenUsageAssistant-Setup-<版本>.exe` 与免安装版 `TokenUsageAssistant-Portable-<版本>.exe`（未做代码签名，见 [INSTALL](INSTALL.md) 与 [RELEASING](RELEASING.md)）。
> 由**用户在自己的 Windows 电脑上**逐项执行并填写「实测记录」（D17 ③，T11.8）；结果计为证据等级 ③。执行模型不能操作这台电脑，所以这里没有「Claude 代测」。任何一项没有实测就不得标为通过；未通过的项记进改进计划第 5 节。
> 1.9.0 正式版的门槛包括「Windows 真机验收通过」（D17 ③）。2026-11-06 起（T15.3，D22）在已发布的 **1.9.0-beta.7** 上做，它已包含阶段 11–14 的全部功能；第 16–22 项是阶段 12–14 在 Windows 上新增的检查。第 16 项（自动更新）只能在 1.9.0 发布后、从 beta.7 升级时测，第 4 项也在那时一并测；其余各项现在就可以做。可选项（第 21、22 项）没有条件就记「未测（没有条件）」。

**填写方式**：在「实测记录」中写日期、被测包的文件名、结果（通过 / 不通过 / 未测）和简短说明；有截图的写文件名即可。**截图与记录里不要出现 API Key、账户邮箱或真实余额以外的账户信息。**

## 1. 下载、核对哈希与 SmartScreen

- **步骤**：用浏览器从 Release 页面下载安装版和 `SHA256SUMS.txt`；在 PowerShell 里运行 `certutil -hashfile TokenUsageAssistant-Setup-<版本>.exe SHA256`，与 `SHA256SUMS.txt` 中对应的一行比对；双击运行安装包。
- **预期**：哈希一致。因为没有代码签名，Windows 可能显示「Windows 已保护你的电脑」，点「更多信息」后出现「仍要运行」，点它继续。浏览器也可能先提示「不常下载」，选择保留。
- **请记录**：实际看到的提示原文（截图即可），以便更正 [INSTALL](INSTALL.md) 里「未在 Windows 真机上实测」的那句说明。

## 2. 全新安装与首次启动

- **步骤**：在没装过本应用的 Windows 用户下运行安装版，按向导选择安装位置；完成后从开始菜单或桌面快捷方式打开。
- **预期**：安装向导可以选择位置；生成开始菜单和桌面快捷方式；首次打开显示主窗口，任务栏图标为刻度环 Logo（不是 Electron 默认图标）；托盘出现本应用的图标——Windows 11 可能把它收进任务栏的「^」里，T11.2 起主窗口会提示怎样固定到任务栏。界面语言跟随系统（中文 Windows 为中文）。总览显示首次启动向导（T11.4，4 步），可以跳过；做完第 4 步后，固定到任务栏的说明也一并收起，之后都不再出现。

## 3. 连接账户与重启后保留

- **步骤**：在「账户与设置」里连接一个你实际在用的账户（例如 Command Code 或 Codex）；退出应用（托盘右键 → 退出助手）再重新打开。
- **预期**：账户保存成功并开始显示额度；重新打开后账户仍在，不需要重新输入。凭据用 Windows DPAPI 加密，只能由当前 Windows 用户解密，不能拷到别的电脑使用。
- **实测记录**：

## 4. 覆盖安装升级（每次发版必测）

- **步骤**：在已保存账户、调整过设置（例如主题、提醒阈值）、移动过主窗口和悬浮窗位置的旧版本上，直接运行新版本的安装包覆盖安装，再打开。
- **预期**：账户、设置、主窗口位置、悬浮窗位置都保留；不需要重新连接；不出现首次启动向导。从 beta.7 升到 1.9.0 时改用应用内的「下载并安装」（第 16 项），升级后同样检查这几点。
- **实测记录**：

## 5. 开机自启

- **步骤**：在「账户与设置」开启「开机启动」（或托盘右键菜单里勾选）；重启电脑并登录。
- **预期**：登录后应用自动启动并驻留托盘，主窗口不弹出（开机启动带 `--hidden` 参数）；关闭开关后再重启，不再自启。
- **实测记录**：

## 6. 托盘图标（T11.2）

- **步骤**：观察托盘图标；把鼠标停在图标上；分别在「设置 → 个性化 → 颜色 → 选择默认 Windows 模式」的浅色与深色下看；如有条件，在 125%、150% 缩放下看。想看告警色，可以把提醒阈值调高（例如 30%），让某个窗口低于阈值。
- **预期**：图标是刻度环，不画数字：平时单色，亮起的部分是最紧账户的剩余；低于阈值时整环带黄，用尽时整环变红，没有数据时只有灰环。浅色、深色任务栏上都看得清；高缩放下不发糊。悬停提示列出各账户的最紧值，账户多时只列前几个，最后写「另 N 个账户」。
- **实测记录**：

## 7. 托盘面板（T11.2）

- **步骤**：左键点托盘图标；再点一次；点面板外的地方；按 Esc；在面板里切换账户后点「主窗口 ›」；右键点托盘图标。如果是 Windows 10，可以把任务栏拖到顶部、左侧、右侧各试一次；有多台显示器时，在托盘所在的屏幕上试。
- **预期**：左键弹出用量面板，贴着任务栏（任务栏在底部时在它上方），不超出屏幕；再点一次图标、点别处或按 Esc 都会收起；面板里切换账户不影响主窗口当前账户；「主窗口 ›」打开主窗口；右键仍是原来的菜单。
- **实测记录**：

## 8. 全部账户与悬浮窗（T11.1）

- **步骤**：保存两个及以上账户；打开主窗口总览；点「全部账户」里的一张卡片；在总览开启悬浮窗，点「展开全部账户」再「收起」；把悬浮窗拖到另一台显示器或改变缩放后再展开收起。
- **预期**：总览顶部列出每个账户，按剩余最少排序，点卡片切换到该账户的详情；悬浮窗收起时只显示最紧的账户，展开后列出全部账户；展开、收起后悬浮窗的底边不动；悬浮窗始终在其他窗口之上。只有一个账户时，总览和悬浮窗与以前相同。
- **实测记录**：

## 9. 睡眠唤醒与锁屏

- **步骤**：让电脑睡眠至少 10 分钟后唤醒；另外锁屏（Win + L）几分钟后解锁。
- **预期**：唤醒或解锁后数据自动刷新，不需要手动点刷新；锁屏期间暂停刷新（T4.4、T8.3）。
- **实测记录**：

## 10. 通知

- **步骤**：在「账户与设置」点「测试通知」；如有条件，等一个窗口低于提醒阈值。
- **预期**：右下角出现系统通知，标题和正文与界面语言一致（中文或英文），没有乱码；点通知打开主窗口。如果系统的「通知」或「专注」设置把它拦住了，请记录。
- **实测记录**：

## 11. 真实编程工具同步

- **步骤**：在「账户与设置 → 工具数据源」添加你实际在用的工具（例如 Codex、Zcode、OpenCode、Gemini CLI、Kimi Code CLI、Qwen Code、Cline，以及不用启动脚本的「Claude Code 会话日志」）；使用一段时间后点同步；打开「用量分析」。
- **预期**：添加时，如果工具在默认位置，会提示「本机已找到 …」，文件选择框直接打开在那个位置（T12.6），仍要你确认；来源卡片显示正常或「部分字段缺失」，不报「格式不兼容」（如果报了，请附诊断信息，只含字段名）；用量分析里有对应时段的数据；不读取对话内容。

## 13. 卸载后数据保留

- **步骤**：在「设置 → 应用」里卸载本应用；查看 `%APPDATA%` 下本应用的数据文件夹是否还在；重新运行安装版。
- **预期**：卸载不删除数据文件夹；重新安装后账户与设置仍在。要彻底删除时，按 [INSTALL](INSTALL.md) 的说明手动删除该文件夹。**请记录**数据文件夹的实际名称。

## 14. 空闲时的资源占用（T11.5）

- **步骤**：打开主窗口和悬浮窗后空闲，在启动后 5 分钟和 30 分钟各记一次「任务管理器 → 详细信息」里本应用各进程的内存与 CPU（可以截图）。
- **预期**：空闲时 CPU 接近 0%（刷新时会短暂升高），内存不持续增长。只记录读数，不做长时间稳定性测试。

## 16. 应用内更新（T12.8，1.9.0 发布后测）

- **步骤**：在已安装的 beta.7 安装版里打开「账户与设置」，确认「检查更新」已开启；1.9.0 发布后重新打开应用（或等它每 24 小时自动检查），出现新版本提示后点「下载并安装」，下载完再点「重启并安装」。另外在免安装版里看同一处。
- **预期**：不点「下载并安装」就不下载；下载后核对校验值，失败时按钮变成「重新下载」；点「重启并安装」后应用重启，版本变为 1.9.0，账户、设置、窗口位置都在（同第 4 项）；免安装版只提示有新版本，不提供下载安装。**请记录**：安装过程中有没有出现 SmartScreen 或用户账户控制（UAC）的提示。
- **实测记录**：

## 17. 英文界面（T14.4）

- **步骤**：「账户与设置」里的「语言 · Language」选 English；依次看主窗口各页、托盘右键菜单、托盘悬停提示、托盘面板、悬浮窗，点「测试通知」，再打开一个对话框（例如导出 CSV 的保存框）；最后改回「跟随系统」。
- **预期**：以上都变成英文，不用重启；账户名和平台返回的原始数据不翻译；改回后恢复中文。**请记录**仍然是中文的文字和它所在的位置（不算不通过，用来补翻译）。
- **实测记录**：

## 18. 余额提醒（T14.2）

- **步骤**：有余额类账户（例如 DeepSeek、Kimi 开放平台、硅基流动）时，在「账户与设置 → PREFERENCES」的「余额提醒金额」里，给它的币种填一个比当前余额高的金额；看托盘图标、托盘面板、总览；然后清空这个金额。
- **预期**：该账户的余额显示「低于提醒金额」并变成琥珀色，托盘图标整环带黄，排序靠前；只弹一次通知，不会反复弹；人民币的提醒只和人民币余额比较，美元同理，不换汇；清空后恢复原样。
- **实测记录**：

## 19. 导出 CSV（T13.4）

- **步骤**：在「用量分析」里点「导出 CSV」，保存后用 Excel（或 WPS）直接双击打开。
- **预期**：中文不乱码；缺失的值是空单元格，不是 0；费用列写明币种，并标明是估算；文件里没有对话内容和密钥。

## 20. 命令行读取额度（T13.5）

- **步骤**：在「账户与设置」开启「命令行读取额度」；把设置里显示的 `tua-status.cmd` 完整路径复制到 PowerShell 或「命令提示符」里运行，再加 `--text` 运行一次；最后关闭这一项。
- **预期**：分别打印 JSON 和文字形式的额度快照，只有额度百分比、重置时间和余额，不含密钥；关闭后这些文件被删除，命令不能再运行。**请记录**：如果公司电脑的组策略禁止运行 PowerShell 脚本，记下报错。

## 21. Claude Code 接入（T13.1、T12.7，可选：这台电脑装了 Claude Code 才测）

- **步骤**：在 Claude 账户的「账户连接」里点「接入所有会话」并确认；直接打开一个 Claude Code 会话（不用助手的启动脚本），发一句话；再在「账户与设置」开启「Claude Code 状态栏」看会话底部；最后回到「账户连接」点「还原」。
- **预期**：如果 `%USERPROFILE%\.claude\settings.json` 里已有你自己的 statusLine，显示「已有自定义状态栏 · 暂不接入」，文件不被修改；没有的话接入成功，会话的套餐额度开始采集，状态栏显示类似「Claude 5h 60% · 最紧 …」；还原后 settings.json 恢复原样，其他设置不变。
- **实测记录**：

## 22. 服务商状态（T14.3，可选，默认关闭）
