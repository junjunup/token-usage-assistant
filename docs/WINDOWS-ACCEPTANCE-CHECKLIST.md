# Windows 真机验收清单

> 适用：Windows 10 / 11 x64，CI 的 Release 工作流产出的安装版 `TokenUsageAssistant-Setup-<版本>.exe` 与免安装版 `TokenUsageAssistant-Portable-<版本>.exe`（未做代码签名，见 [INSTALL](INSTALL.md) 与 [RELEASING](RELEASING.md)）。
> 由**用户在自己的 Windows 电脑上**逐项执行并填写「实测记录」（D17 ③，T11.8）；结果计为证据等级 ③。执行模型不能操作这台电脑，所以这里没有「Claude 代测」。任何一项没有实测就不得标为通过；未通过的项记进改进计划第 5 节。
> 1.9.0 正式版的门槛包括「Windows 真机验收通过」（D17 ③）。第 6、7 项要等 T11.2（托盘面板与状态图标）进包后才能测；包里还没有的项记为「未测（包里没有）」。

**填写方式**：在「实测记录」中写日期、被测包的文件名、结果（通过 / 不通过 / 未测）和简短说明；有截图的写文件名即可。**截图与记录里不要出现 API Key、账户邮箱或真实余额以外的账户信息。**

## 1. 下载、核对哈希与 SmartScreen

- **步骤**：用浏览器从 Release 页面下载安装版和 `SHA256SUMS.txt`；在 PowerShell 里运行 `certutil -hashfile TokenUsageAssistant-Setup-<版本>.exe SHA256`，与 `SHA256SUMS.txt` 中对应的一行比对；双击运行安装包。
- **预期**：哈希一致。因为没有代码签名，Windows 可能显示「Windows 已保护你的电脑」，点「更多信息」后出现「仍要运行」，点它继续。浏览器也可能先提示「不常下载」，选择保留。
- **请记录**：实际看到的提示原文（截图即可），以便更正 [INSTALL](INSTALL.md) 里「未在 Windows 真机上实测」的那句说明。

## 2. 全新安装与首次启动

- **步骤**：在没装过本应用的 Windows 用户下运行安装版，按向导选择安装位置；完成后从开始菜单或桌面快捷方式打开。
- **预期**：安装向导可以选择位置；生成开始菜单和桌面快捷方式；首次打开显示主窗口，任务栏图标为刻度环 Logo（不是 Electron 默认图标）；托盘出现本应用的图标——Windows 11 可能把它收进任务栏的「^」里，T11.2 起主窗口会提示怎样固定到任务栏。

## 3. 连接账户与重启后保留

- **步骤**：在「账户与设置」里连接一个你实际在用的账户（例如 Command Code 或 Codex）；退出应用（托盘右键 → 退出助手）再重新打开。
- **预期**：账户保存成功并开始显示额度；重新打开后账户仍在，不需要重新输入。凭据用 Windows DPAPI 加密，只能由当前 Windows 用户解密，不能拷到别的电脑使用。
- **实测记录**：

## 4. 覆盖安装升级（每次发版必测）

- **步骤**：在已保存账户、调整过设置（例如主题、提醒阈值）、移动过主窗口和悬浮窗位置的旧版本上，直接运行新版本的安装包覆盖安装，再打开。
- **预期**：账户、设置、主窗口位置、悬浮窗位置都保留；不需要重新连接；不出现首次启动向导（T11.4 进包后）。
- **实测记录**：

## 5. 开机自启

- **步骤**：在「账户与设置」开启「开机启动」（或托盘右键菜单里勾选）；重启电脑并登录。
- **预期**：登录后应用自动启动并驻留托盘，主窗口不弹出（开机启动带 `--hidden` 参数）；关闭开关后再重启，不再自启。
- **实测记录**：

## 6. 托盘图标（T11.2）

- **步骤**：观察托盘图标；把鼠标停在图标上；分别在「设置 → 个性化 → 颜色 → 选择默认 Windows 模式」的浅色与深色下看；如有条件，在 125%、150% 缩放下看。想看告警色，可以把提醒阈值调高（例如 30%），让某个窗口低于阈值。
- **预期**：图标是刻度环，不画数字：平时单色，亮起的部分是最紧账户的剩余；低于阈值时整环带黄，用尽时整环变红，没有数据时只有灰环。浅色、深色任务栏上都看得清；高缩放下不发糊。悬停提示列出各账户的最紧值，账户多时只列前几个，最后写「另 N 个账户」。
- **实测记录**：

## 7. 托盘面板（T11.2）

- **步骤**：左键点托盘图标；再点一次；点面板外的地方；按 Esc；在面板里切换账户后点「主窗口 ›」；右键点托盘图标。如果是 Windows 10，可以把任务栏拖到顶部、左侧、右侧各试一次；有多台显示器时，在托盘所在的屏幕上试。
- **预期**：左键弹出用量面板，贴着任务栏（任务栏在底部时在它上方），不超出屏幕；再点一次图标、点别处或按 Esc 都会收起；面板里切换账户不影响主窗口当前账户；「主窗口 ›」打开主窗口；右键仍是原来的菜单。
- **实测记录**：

## 8. 全部账户与悬浮窗（T11.1）

- **步骤**：保存两个及以上账户；打开主窗口总览；点「全部账户」里的一张卡片；在总览开启悬浮窗，点「展开全部账户」再「收起」；把悬浮窗拖到另一台显示器或改变缩放后再展开收起。
- **预期**：总览顶部列出每个账户，按剩余最少排序，点卡片切换到该账户的详情；悬浮窗收起时只显示最紧的账户，展开后列出全部账户；展开、收起后悬浮窗的底边不动；悬浮窗始终在其他窗口之上。只有一个账户时，总览和悬浮窗与以前相同。
- **实测记录**：

## 9. 睡眠唤醒与锁屏

- **步骤**：让电脑睡眠至少 10 分钟后唤醒；另外锁屏（Win + L）几分钟后解锁。
- **预期**：唤醒或解锁后数据自动刷新，不需要手动点刷新；锁屏期间暂停刷新（T4.4、T8.3）。
- **实测记录**：

## 10. 通知

- **步骤**：在「账户与设置」点「测试通知」；如有条件，等一个窗口低于提醒阈值。
- **预期**：右下角出现系统通知，标题和正文是中文，没有乱码；点通知打开主窗口。如果系统的「通知」或「专注」设置把它拦住了，请记录。

## 11. 真实编程工具同步

- **步骤**：在「账户与设置 → 工具数据源」添加你实际在用的工具（例如 Codex、Zcode、OpenCode、Claude Code）；使用一段时间后点同步；打开「用量分析」。
- **预期**：来源卡片显示正常或「部分字段缺失」，不报「格式不兼容」（如果报了，请附诊断信息，只含字段名）；用量分析里有对应时段的数据；不读取对话内容。

## 13. 卸载后数据保留

- **步骤**：在「设置 → 应用」里卸载本应用；查看 `%APPDATA%` 下本应用的数据文件夹是否还在；重新运行安装版。
- **预期**：卸载不删除数据文件夹；重新安装后账户与设置仍在。要彻底删除时，按 [INSTALL](INSTALL.md) 的说明手动删除该文件夹。**请记录**数据文件夹的实际名称。

## 14. 空闲时的资源占用（T11.5）

- **步骤**：打开主窗口和悬浮窗后空闲，在启动后 5 分钟和 30 分钟各记一次「任务管理器 → 详细信息」里本应用各进程的内存与 CPU（可以截图）。
- **预期**：空闲时 CPU 接近 0%（刷新时会短暂升高），内存不持续增长。只记录读数，不做长时间稳定性测试。
