# Token 用量助手 1.5.1：本机订阅连接改进

本版改进 ChatGPT / Codex 的连接步骤，明确区分套餐额度与工具明细。仍处于阶段 3 之前的订阅适配补充；未新增按量账户、macOS 或中转接入。其他支持范围沿用 [1.5.0 说明](SUBSCRIPTIONS-1.5.0.md)，连接步骤以本文为准。

## 使用步骤

1. 在官方 Codex 客户端登录 ChatGPT 订阅账户。
2. 打开助手 **账户与设置 → 平台 → ChatGPT · Codex → 连接本机 Codex**。
3. 助手检查已保存的配置、自定义 `CODEX_HOME` 和当前用户默认 `.codex`。只有一个配置位置时直接通过官方客户端验证登录并读取额度；多个位置时在应用内选择，再点击“连接所选配置”。配置目录存在不等于已经登录。
4. 没有找到配置时才打开目录选择器；也可随时点击“手动选择目录”。找不到官方 Codex 程序时仍需选择 `codex.exe`。

更新已有连接优先使用原位置；原目录丢失时不会直接换绑另一个配置。自动识别只检查上述位置，不遍历磁盘、不直接读取登录令牌。取消选择不保存账户，不显示成功提示。

额度连接与工具分析分别显示状态：没有 `sessions` / `archived_sessions`、工具来源添加失败或处于停用状态，都不撤销成功的额度连接。产生日志后可重新连接以添加来源，或在“工具数据源”中添加。再次连接不重复添加来源，也不会自动启用用户已停用的来源。

Claude 仍采用本地统计组件。点击连接首先表示 **组件已就绪 · 等待首次额度**；在项目目录运行生成的 `Start-Claude.ps1`，收到有效额度后才显示 **额度已同步**。过期观察值与工具明细另行显示，不把“组件创建成功”当成真实订阅数据已到达。

- 桌面回归 **165 项通过，0 失败、0 跳过**；Sites 兼容 **4 项通过**。

- 1.5.0 → 1.5.1 完成 **23 项原生模块升级检查**，覆盖旧平台账户、偏好、窗口位置、缓存、价格、Zcode 来源保留。订阅绑定和来源持久化另有桌面回归；不是实际 NSIS 覆盖安装测试。
- 本机发现 **1 个 Codex 配置**，自动找到默认目录及程序，目录 / 程序选择器调用均为 **0**。本次仅验证发现流程，未重新查询真实额度；1.5.0 的真实 Pro 只读查询记录仍作为之前的证据保存。
- 安装版与免安装版载荷一致，**83 个打包文件**与当前源码 / 前端构建一致。具体哈希见交付清单及 `docs/verification-1.5.1`。

原生自检使用 `--disable-gpu`，正常启动不强制该参数。Claude、GLM、MiniMax、火山真实账户核账仍待补充。按用户要求未重启长时间稳定性测试；未进行本轮实际安装覆盖、重启或休眠恢复验收。程序仍为未签名的本地开发交付。

## 更新

退出旧版助手后，运行新版安装程序，或使用新版免安装 EXE。账户和偏好使用原本机存储，不需要重建；仅替换程序不会注销官方客户端。既有版本与发布文件保留。本版不自动结束正在运行的旧程序，也不代替用户执行覆盖安装。

开发交接新增 `desktop/codex-connect.cjs`、`desktop/subscription-status.cjs` 与 `tests/codex-connect.test.cjs`。配置选择结果只有确认后才验证账户；工具源附加失败返回独立提示。后续仍按原计划进入 DeepSeek 官方按量账户，再进行关联核对、macOS 与第三方评估。
