# Token 用量助手 1.5.0：ChatGPT / Claude 订阅接入

本版在阶段 3（DeepSeek 官方按量账户）前增加订阅适配，同时交付额度看板与本机工具分析。保留 1.4.1 的悬浮窗位置修复、Command Code / Zcode、首批 Coding Plan 和 Harness。DeepSeek 按量余额、账户关联、macOS、第三方中转仍属于后续阶段。

## 从哪里连接

1. 打开 **账户与设置 → 平台 → ChatGPT · Codex**。先在官方 Codex 登录 ChatGPT，再点击“连接本机 Codex”，选择含 `sessions` 的配置目录（通常是用户目录下的 `.codex`）。程序优先发现 Codex 桌面版自带的 `codex.exe`；无法发现时选择官方 CLI 可执行文件。无需 API Key，不复制登录令牌。
2. 打开 **账户与设置 → 平台 → Claude · Claude Code**，点击“连接并生成采集配置”。程序打开本机组件目录。先用官方 Claude Code `/login` 登录订阅，然后在项目目录的 PowerShell 中运行生成的 `Start-Claude.ps1`。窗口内会使用用量助手的简短状态栏。
3. 连接时添加对应的独立工具数据源；也可在下方“工具数据源”中手工添加。额度在 **用量总览**，Token、模型、项目和会话在 **用量分析 → 工具分析**。可多选来源，停用或移除其中一个。

Claude 启动配置只对该次启动有效，原有 Claude 设置文件与状态栏配置保留。已有定制遥测出口的用户，应先核对本次启动配置，避免覆盖该会话所需的出口。关闭用量助手后组件失败会自行退出，不阻断 Claude；该时段的事件可能丢失，不能补成完整历史。

## 支持范围与统计口径

| 能力 | ChatGPT / Codex | Claude / Claude Code |
|---|---|---|
| 订阅额度 | 官方 app-server `account/read` 与 `account/rateLimits/read`；使用返回的全部额度池、窗口长度和重置时间 | 官方状态栏 `rate_limits.five_hour`、`seven_day`；未出现的窗口保持缺失 |
| 登录 | 使用用户选定的本机官方客户端现有 ChatGPT 登录 | 使用用户在 Claude Code 的订阅登录，不提取 Cookie / OAuth 凭据 |
| 工具明细 | 0.155.x rollout 的白名单用量字段；实际核验版本为 0.155.0-alpha.16.4 | 官方 OTLP JSON `api_request` / `api_error` 元数据；支持 2.1.251 及以上的 2.1.x 字段合同 |
| 覆盖 | 当前选择的本机日志。日志缺失、未知版本、快照缺口均不保证完整 | 启动组件后、助手运行期间接收到的事件；不补采历史会话 |
| 请求次数 / 终态 | 用量快照不是请求次数，终态未知，不参与成功率或已完成请求均值 | 有稳定 ID 的终态事件去重；无用量的错误保持未知；未报告的中间重试不可计数 |
| 网页聊天 | 不采集 ChatGPT 网页聊天明细；Codex 配额不代表全部 ChatGPT 权益 | 不采集 Claude 网页聊天明细；共享窗口以状态栏返回为准 |
| 费用 / 账单 | 工具费用仅按本机单价估算；无订阅真实账单 | 同左，不把 Claude 上下文大小或估算费用冒充账单 |

Codex 的累计计数用于识别重复快照；每条记录使用明确返回的最近用量。继承的历史事件按原时间排除，计数下降作为新的观察基线，不重复收取旧 `last_token_usage`。不同来源副本出现重叠时停止合并该副本。缺少中间事件时不把累计差额猜分给模型或请求。未知版本明确提示，不能静默使用猜测解析。

缓存读写属于输入分类，推理属于输出分类，不重复加到总量。Claude 输入为普通输入、缓存读取、缓存创建之和；Codex 输入已包含缓存。缺少分类不填零。所有工具数据依旧 `accountId:null`，不借用当前选中账户账期，不与平台额度相加。

Claude 保留额度的观察时间。状态栏重绘时数值未变化，不假装完成新的平台查询；五分钟未观察到变化、窗口已过期或采集器停止时显示最近观察值，且不根据旧值发送额度提醒。因此“旧数据”可能意味着数值没有变化，并不一定是断网。Claude 状态栏未提供可靠计费账户身份，本版标为本机订阅观察，不能自动完成多账户核账；多个登录身份并行使用应视为未核验范围。

## 隐私与本机存储

- Codex 通过官方客户端查询额度，助手只保存本机配置路径和脱敏登录绑定。登录账户变化时停止使用旧连接；更新连接后重新读取。助手不调用模型、不购买、不消耗重置券、不注销官方客户端。
- Codex JSON 解码只投影白名单字段，跳过提示词、回复、指令和工具结果，不写入索引或错误日志。
- Claude 接收器仅绑定 `127.0.0.1`，需要随机本机认证令牌，拒绝浏览器 Origin，限制请求大小与连接数。OTLP 配置关闭正文和原始 API 内容，接收后再次投影白名单，不保存原始报文。无任何云端转发。
- 组件、元数据导出和设置保存在助手自己的 userData 子目录。原账户凭据、偏好、窗口位置及旧 Zcode 迁移文件保留。移除工具来源不删除其原始日志；移除订阅连接不会注销 Codex / Claude。
- 不要把生成的 `collector.json` 或 `claude-settings.json` 作为源码公开。交付源码包排除真实用户数据、日志、运行时和临时验证目录。
