# Token 用量助手 1.4.0：双工具采集与验证说明

更新：2026-09-24。Windows x64；本次范围为计划中的阶段 1、2。阶段 0 维护并行进行，后续 DeepSeek 余额、账户关联、macOS 和第三方评估分别推进。

## 本版交付

- 平台账户与工具数据源分别管理；工具用量不借用当前账户身份、余额或账期。
- 工具来源可添加、改名、选择位置、启停、移除和同步，显示最近成功时间。原有 Zcode 位置自动迁移，旧配置保留供回退。
- Zcode 和 DeepSeek Harness 可分别查看，也可选择多个来源。模型、项目、会话筛选统一作用于总计、趋势和分组。
- 新增已报告用量口径：失败或取消的尝试只要明确报告了 usage，也计入工具用量。完成率与完成请求均值单独计算。
- Harness 可选插件只向本机导出白名单元数据，助手用自己的 SQLite 索引增量读取。相同尝试取最新版本，重试独立计数。
- 本机模型价格支持明确的 USD / CNY。旧价格沿用 USD；不同币种分别显示，不换汇。估算不是账单。
- 保留 Command Code、首批 Coding Plan、多账户、托盘、悬浮窗和现有视觉交互。

## 使用步骤

1. 启动本版程序，进入“账户与设置 → 工具数据源”。平台账户配置与工具来源配置相互独立。
2. 原有 Zcode 会保留所选数据库。新增 Zcode 来源时选择对应 SQLite 文件；助手只读用量字段，不修改数据库。
3. 使用 Harness 时，先按 [插件安装说明](../integrations/deepseek-harness/README.md) 把随附插件添加到实际使用的 profile，再在助手中选择插件生成的 `usage.jsonl`。同目录的 `source.json`、`status.json` 应保留。
4. 点击“同步”查看状态；在“用量分析 → 工具分析”选择一个或多个来源，再选择今日/近 7 天、模型、项目或会话。
5. 在模型排行中设置每百万 Token 的单价和币种。未设置价格或字段不足时显示未知/已知部分。

助手中的“停用来源”暂停该来源的读取与合计，Harness 插件仍可继续导出；重新启用来源会读取专用 JSONL 中已经导出的增量。需要停止 Harness 自身导出时，应按插件说明卸载或停用插件；插件停用期间的缺失不会通过读取原始会话历史补齐。

## 统计与准确性规则

- 每条工具记录保留来源、请求/尝试身份、时间、模型、项目、会话、状态及用量出处，`accountId` 为 `null`。未来账户关联需要独立实现。
- 同一 Harness 尝试的多行记录按最大 revision 更新，不按行数累加。失败后的重试是另一次尝试。终态不含新 usage 时保留此前已报告的 usage。
- 分叉继承的事件不会作为子会话的新调用；子任务新调用由自己的会话身份区分。
- Zcode 的缓存属于输入子分类；Harness 的未缓存输入、缓存读取和写入互斥。推理属于输出子分类，均不重复加入总量。
- 缺失字段保持未知；未知完整总量时显示已知 Token 及缺失请求数。未报告 usage 的请求不当成免费或 0 Token。
- 完成率为完成 /（完成 + 失败）；取消与其他状态单列。均值仅使用完成请求；工具用量总计包含失败/取消时明确报告的用量。
- 工具统计和平台总量不能相加。没有明确账户关联，工具的“本账期”不可用；没有可比时间覆盖，也不会计算虚假同期差异。
- 覆盖范围仅表示已经观察到的记录时间，不证明整个时段完整。插件停用、异常、格式变化、缺少尝试起点或未写完文件尾部都会影响覆盖。
- 原始币种保留，USD 与 CNY 分列；账户实际接口费用与本机估算在不同视图中呈现。
- 同一路径、硬链接及同一 Harness 安装的导出副本不能重复添加。没有可靠安装身份的 Zcode 副本，如与另一已选来源出现相同请求身份/会话/时间/模型，会暂停后加入来源的合并并提示“来源重叠”；仍可单独查看。不会读取正文来计算指纹。

## 本机存储、升级和回退

继续使用原 appId 与 userData；免安装版也使用当前 Windows 用户的应用数据目录。凭据仍使用 Windows DPAPI，无明文回退。

| 文件 | 作用 |
|---|---|
| `accounts.encrypted.json`、`settings.json` | 原有账户、偏好及窗口位置，保留 |
| `local-source.json` | 1.3.0 的 Zcode 选择，首次迁移后保留 |
| `tool-sources.json` | 新来源身份、位置、名称和启停状态 |
| `tool-source-status.json` | 最近成功时间及观察时间；重启后重新确认同步状态 |
| `tool-usage.sqlite` 及 WAL/SHM | 助手自己的 Harness 元数据索引，可重建，不是工具原文件 |
| `local-pricing.json` | 模型单价；旧条目没有币种时解释为 USD |

索引不包含提示词、回复正文、工具结果、错误正文、Key 或原始 payload。Zcode 只通过白名单 SELECT 读取元数据；Harness 插件不扫描历史会话文件。路径、模型和项目属于本机用量元数据，不做云同步。

损坏的来源配置会阻止覆盖并显示错误。移除来源会清理助手对应索引，不删除工具原文件。保留插件导出的整套目录可重新导入。迁移 Harness 路径时需保留来源身份；另一安装应新增来源。旧版本不认识新增的 Harness 设置，但旧 Zcode 选择、账户和偏好可回读。升级前后不要同时编辑同一配置目录。

## 复验与后续

常规：`pnpm run test:desktop`、`pnpm run build`、`pnpm run test:sites`。没有隔离 Harness 测试运行时的机器，官方安装包/CLI 检查会明确跳过；完整复验步骤见插件 README。

原生程序：`TokenUsageAssistant-Portable-1.4.0.exe --smoke-test --test-directory=<新的隔离目录>`。不得将真实用户数据目录用作自检目录。

两小时：从源码根目录运行 `node scripts/soak-tools.cjs --duration-ms=7200000 --interval-ms=30000 --output=work/soak-1.4.0-verify`。输出必须是项目 `work` 下名称以 `soak-` 开头的新目录或空目录；已有结果时请使用新的目录名。应核对起止实际时间、源码哈希、错误数与最终 `validationComplete`，不能把加速短测当成长测。

阶段 3 首先实现 DeepSeek 官方 `/user/balance`，只承诺余额及币种/赠金/充值拆分；完整历史账单接口尚未确认。阶段 4 再做明确账户关联和同范围核对，阶段 5 Apple Silicon macOS，阶段 6 第三方能力评估。本版没有开通这些功能。
