# Token 用量助手 1.8.0-beta.2：Mac Codex 连接修复

2026-09-26。仍为 Apple Silicon / macOS 13+ 开发测试版，Mac 真实额度连接待复测。

## 这次报告说明了什么

r2 诊断已成功运行并验证原应用包。自动发现选中了 Homebrew Codex CLI **0.39.0**，进程在初始化阶段约 **49 ms** 以退出码 **2** 结束，stderr 分类为启动参数不兼容。未进入账户登录状态和额度查询；报告不支持将这次失败归因于网络或登录超时。报告不含原始 stderr，因此不推断具体是哪一个参数被拒绝。

诊断自动发现的程序不一定等同于已保存连接的程序；是否完成官方桌面端登录，仍需在 Mac 上确认。原助手将进程启动失败、提前退出和真正超时合并提示，是本次需要修复的应用问题。

## 已有测试包如何升级（推荐）

使用 `TokenUsageAssistant-Mac-Update-1.8.0-beta.2.zip`，无需重传 Electron：

1. 在 Mac 完整退出用量助手（Command-Q 或应用菜单退出）。保留原先能启动的首测包目录。
2. 将升级 ZIP 发到 Mac 并完整解压。双击 `Update-Mac-Trial.command`，选择原先包含 `app.asar` 和 `Start-Mac-Trial.command` 的首测包目录。
3. 脚本检查原版本和文件哈希，备份旧应用文件，再升级到 beta.2。保持现有 Electron 运行目录和 Application Support 中的账户、设置不变；不读取或修改 Codex 凭据。
4. 仍从原目录双击 `Start-Mac-Trial.command`，确认应用版本为 **1.8.0-beta.2**。
5. 官方 Codex 桌面客户端应已登录 ChatGPT。回到助手点“连接本机 Codex”；已有连接使用“更新连接”。若弹出程序选择框，选择官方 **Codex.app**（通常在“应用程序”中），不用展开应用包，也不要选择 `.codex` 配置文件夹。
6. 预期看到套餐额度；若仍失败，记录新版助手显示的完整错误文字。此前只针对 beta.1 的 r2 诊断包不适用于升级后的应用。

升级支持原始 beta.1 或已经完成本次升级的 beta.2。若提示原应用哈希不符，会停止，不覆盖未知版本。备份保存在原包目录下 `.upgrade-backup.*`，升级失败自动恢复；无需复制 Windows 凭据或重装 Electron。目录名可能仍含 beta.1，实际版本以应用内显示为准。

另提供完整 `TokenUsageAssistant-Mac-arm64-Trial-1.8.0-beta.2.zip`，适合没有旧包的机器。它仍是官方 Electron 运行环境与应用 ASAR 的开发运行包，**不是已签名、公证的独立 Mac 应用**。之前遇到启动拦截的这台 Mac 应优先用小型升级包复用已修复的环境。

## 修复范围

- 连接前使用只含 initialize / initialized 的短时预检验证本机协议，不调用模型、登录变更或额度接口。原程序兼容时继续沿用；不兼容时尝试其他已知位置，最后由用户选择官方程序。最多检查 8 个自动发现候选，物理路径去重。
- Mac 可直接选择 `.app`，只读取其中已知的 `Contents/Resources/codex` 可执行位置，不运行 GUI 入口、不扫描整盘。
- 配置目录与账户绑定规则不变；仅在实际额度查询成功后保存新程序。取消选择或失败不会覆盖旧连接、重新启用停用数据源或改工具记录的账户归属。
- 区分程序启动失败、参数 / 协议不支持、提前退出、查询异常和超时。初始化、登录状态和额度阶段分别计时并给出对应提示。预检上限 8 秒；正式查询各阶段上限 20 秒。早退不延长等待。
- stderr 仅在内存中做枚举分类，不写原文；错误不含凭据、正文或原始服务器错误。
- 不增加旧版 CLI 协议适配，不修改或自动升级用户的 Codex / Homebrew。额度查询兼容性与日志格式兼容性分开：工具日志解析仍限已验证的 0.155.x。

协议依据：[OpenAI 官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。使用 stdio、初始化握手、`account/read`（refreshToken false）与 `account/rateLimits/read`；未使用模型、会话创建、登录 / 注销或额度重置 API。

234 项桌面测试和 4 项兼容测试通过；新增覆盖旧 CLI 参数拒绝、初始化预检、分阶段超时、错误脱敏、坏程序回退、Mac 应用包路径、取消不保存和原配置保持。最终 Windows 包、包内协议模块、升级保留与交付文件的结果见 `verification-1.8.0-beta.2`。

以上样例和 Windows 原生检查不替代真实 Mac 连接、钥匙串、系统选择框、菜单栏、休眠恢复、安装升级、登录项或签名公证验收；没有新增长期稳定性测试或真实账户核账。

Mac 试运行数据目录保持 `~/Library/Application Support/TokenUsageAssistant`。试运行模式仍不支持登录自动启动。其他阶段 5 待测项目沿用 `MAC-TRIAL-1.8.0-beta.1.md`。
